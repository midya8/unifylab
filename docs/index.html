01 / define the equations

Finite trees.
Shared variable names.

Variables are strings like "?x". Constructors are arrays like ["box", "?x"]; constants are ["amber"]. The same constructor name always has the same arity. Equal variable names are shared across every equation.

Loading controls.

03 / inspect a rewrite

Nothing disappears
without a rule.

Always process the first pending equation. Delete equality; orient a nonvariable left side; check occurrence before eliminating a left variable; otherwise clash or decompose constructors. Decomposition prepends children left to right. Bindings are fully composed at each elimination.
