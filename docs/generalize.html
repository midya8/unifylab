03 / ordered pair identity

Same pair.

Left and right roles matter. The pair (amber, blue) is different from (blue, amber); matching only one side is not enough. Each distinct disagreement pair gets one variable. A repeated pair must reuse it.

Path indices are zero-based constructor-child positions. Root is []. Visit children left to right; record a retained constructor after its children.
